# FinVision

Egyptian Startup Intelligence System

FinVision helps founders in Egypt ask questions about their business and review financial data. The RAG chatbot answers with sources. The financial datasets support the team's ML work.

## Where to start

| I want to | Go to |
| --- | --- |
| Run or test the chatbot | [RAG setup](rag/README.md) |
| Trace a chatbot source or update evidence | [Knowledge base](data/knowledge_base/README.md) |
| Work on bankruptcy prediction | [Poland bankruptcy data](data/poland/README.md) |
| Find Egypt and regional economic indicators | [World Bank data](data/world-bank/README.md) |

The [data guide](data/README.md) lists the files, their sources, and which work uses them.

## Project data

- [Poland bankruptcy data](data/poland/README.md) for training and evaluating the ML models.
- [World Bank indicators](data/world-bank/README.md) for economic analysis in Egypt and comparator economies.

The [data guide](data/README.md) links to the files, sources, and formats.
